# Бесплатный запуск CRM на своём компьютере

CRM работает на компьютере в мастерской. Платить за сервер не нужно. Телефоны и другие компьютеры подключаются к ней по Wi-Fi мастерской.

**Ограничения:** CRM доступна, только пока компьютер включён и окно CRM открыто. Из дома или с мобильного интернета она не откроется. Для продажи коллегам понадобится сервер (см. `deploy/README.md`).

## Установка (один раз, Windows)

1. **Node.js.** Откройте https://nodejs.org и нажмите зелёную кнопку **LTS**. Запустите скачанный файл и нажимайте «Next», в конце «Install».
2. **CRM.** Откройте https://github.com/kismmbiz-alt/ki и нажмите зелёную кнопку **Code**, затем **Download ZIP**.
3. **Распаковка.** Щёлкните по скачанному ZIP правой кнопкой и выберите «Извлечь всё…». В строке пути напишите `C:\crm` и нажмите «Извлечь».
   > Путь должен быть без русских букв, иначе база данных не запустится.
4. **Запуск.** Откройте папку `C:\crm\ki-main` и дважды щёлкните **«Запустить CRM.bat»**.
   - Если Windows пишет «Windows защитил ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае».
   - Если брандмауэр спросит про доступ к сети, нажмите «Разрешить». Без этого CRM не откроется с телефонов.
5. Первый запуск занимает 5–10 минут: программа скачивает компоненты и собирается. Потом сама откроется в браузере. Нажмите «Зарегистрировать мастерскую».

## Каждый день

- Утром дважды щёлкните «Запустить CRM.bat». **Не закрывайте чёрное окно**, пока работаете.
- В окне написан адрес для телефонов, например `http://192.168.1.5:3000`. Откройте его в браузере телефона, подключённого к Wi-Fi мастерской, и добавьте на главный экран.
- Чтобы выключить CRM, закройте чёрное окно.

## Отдельный компьютер как сервер

Если CRM стоит на отдельном компьютере, остальные работают с ним через браузер по Wi-Fi.

1. **Не давать компьютеру засыпать.** Пуск → «Параметры» → «Система» → «Питание» (в Windows 10: «Питание и спящий режим»). В пункте «Переводить в спящий режим» выберите «Никогда». Экран можно отключать, это не мешает.
2. **Запуск сам при включении.** Нажмите клавиши Win+R, введите `shell:startup` и нажмите Enter. Откроется папка «Автозагрузка». Правой кнопкой по файлу «Запустить CRM.bat» → «Показать дополнительные параметры» → «Создать ярлык». Перетащите ярлык в папку «Автозагрузка».
3. **Постоянный адрес (по желанию).** Адрес вида `192.168.1.5` может смениться после перезагрузки роутера. Тогда посмотрите новый адрес в чёрном окне. Чтобы он не менялся, в настройках роутера найдите «Резервирование адресов» (DHCP) и закрепите адрес за этим компьютером.
4. На остальных компьютерах и телефонах откройте адрес из чёрного окна в браузере и добавьте его в закладки.

## Данные и копии

- Все данные хранятся в папке `C:\Users\Public\crm-data`, отдельно от программы.
- При каждом запуске CRM сама делает копию базы за день в `C:\Users\Public\crm-data\backups`. Хранятся последние 14 копий.
- Раз в неделю копируйте папку `crm-data` на флешку или в облако. Если сломается диск, данные восстановятся только из такой копии.

## Обновление

Скачайте новый ZIP (шаг 2), распакуйте его в новую папку, например `C:\crm2`, и запустите «Запустить CRM.bat» уже оттуда. Данные подхватятся сами. Старую папку потом можно удалить.

## macOS и Linux

Установите Node.js (шаг 1), распакуйте архив и запустите в терминале `./start-local.sh`. Данные хранятся в папке `~/crm-data`.
